# 恢复与迁移

## 正常卸载

关闭 VibeFlow 及其工具，使用独立 Python 执行 `patch.py uninstall --app "软件根目录"`。工具会检查备份和当前文件，恢复原版字节，保留 `.vfzh` 中的备份。再次卸载只验证恢复结果。

## 进程中断

安装器使用 `.vfzh/operation.lock` 阻止并发操作。若机器断电或进程被强制结束，先确认没有补丁工具正在运行，再移除这一锁文件。不要删除整个 `.vfzh`。

安装记录若显示 `backed-up` 或 `restoring`，运行 `uninstall` 恢复。它只接受与已知原版或补丁哈希相符的目标，不覆盖未知修改。备份缺失或损坏时停止，请使用自己的原版安装包恢复。

## 软件升级

先卸载本补丁，再更新软件。更新后的构建需要重新提取文字、审核翻译、更新兼容性清单并完整验证；不要通过修改 `compatibility.json` 跳过不兼容检查。

## 此前本地版迁移

2026-10-03 的本地部署使用 `Manage-VibeFlowChinese.ps1`，与本仓库 `.vfzh` 记录不通用。如已安装该版本：

1. 关闭应用，用第二版管理目录中的脚本执行 `-Mode Restore`，恢复第一版。
2. 用第一版管理目录中的脚本执行 `-Mode Restore`，恢复原版。
3. 保留两版备份，执行本仓库 `check`，通过后再 `build` / `install`。

无需迁移也能继续使用原先已安装的第二版；本仓库只是便于独立构建、分享和维护。
